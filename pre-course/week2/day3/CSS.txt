CSS: 웹 페이지의 스타일링과 레이아웃 등 디자인을 지정
- 상위 요소의 스타일이 하위 요소에 상속, 우선순위에 따라 cascading하게 적용

선택자: 스타일을 적용할 HTML 요소를 선택(태그이름, 클래스, 아이디 등)

선택자 {
	속성: 값;
	속성: 값;
}

외부 스타일 시트: .css 확장자 파일을 만들고 <link> 태그를 사용하여 HTML 문서와 연결 (가장 권장됨)
<head>
	<link rel="stylesheet" href="style.css">
</head>
인라인과 내부 스타일은 쓸 수는 있지만 권장되지 않음

전체 선택자: *를 사용하여 모든 HTML 스타일 적용 (잘 쓰진 않음)

태그 선택자: 태그 스타일 적용

클래스 선택자: .클래스 이름 ( 가장 많이 사용 )

id 선택지: #id 로 사용

자손, 자식, 부모: 태그 안에 있으면 자식이자 자손, 더 안에 있으면 자손

공백을 사용하여 자손, >를 사용하여 자식 지정

그룹선택자: ,를 사용하여 여러 선택자를 그룹으로 묶어 지정

가상선택자: 특정 목적을 위해 추가
- 가상 클래스 선택자 (특정 상태)
(:hover, :active 등)
- 가상 요소 선택자 (특정 요소의 일부분)
(::before, ::first-letter 등)

우선 순위
- !important > 인라인 선언 > id 선택자 > class 선택자 > 태그 선택자 < 전체 선택자
우선 순위가 같을 경우 선택자가 많은 것 우선 적용, 이것도 같다면 가장 뒤에 작성된 스타일 적용

네트워크 모델, TCP 프로토콜 등

MAC - 기기에 부여된 고유 번호
IP주소 - 네트워크에 연결된 장치를 식별할 수 있게 부여되는 주소

공인 IP - 전 세계에서 고유
사설 IP - 내부 네트워크에서 사용 (외부와는 차단됨)
- NAT을 사용해서 통신 가능

온프레미스: 내 컴퓨터가 서버
클라우드: 외부 데이터 센터가 서버
- 비용, 탄력성, 보안, 성능 최적화 등에서 장단점 존재

VPC: AWS 클라우드 내에 구성한 독립적인 클라우드 네트워크

보안 그룹: 인바운드, 아웃바인드 규칙을 인스턴스 수준에서 개별로 설정
- ACL: 서브넷 수준

컴퓨팅: EC2
- 컴퓨팅 자원 임대, 실제 사용량만큼 지불
- OS, CPU, RAM 등 컴퓨팅 자원
- 하드웨어, 소프트웨어를 지정하여 EC2 인스턴스 생성
- EC2 보안 그룹으로 인바운드/아웃바운드 규칙 설정 가능

스토리지: S3
DB: RDS
네트워크: VPC
- EC2 네트워크 설정을 위한 요소

보안: IAM

IAM: AWS 리소스에 접근을 안정하게 제어
- Root: 계정 생성 시 이메일 계정으로 모든 권한 소유
- User: 실제 작업을 위해 생성하는 개별 계정

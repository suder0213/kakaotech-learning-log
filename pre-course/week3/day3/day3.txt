리액트 접근법 : 요소 바꿀 때 DOM 추적하는게 너무 복잡
-> 상태가 바뀌면 화면은 리액트가 알아서 처리

가상 DOM: 실제로 변경된 부분만 랜더링

JSX: JS 안에서 HTML을 쓸 수 있음

함수 컴포넌트: 함수 return을 html 형식으로 작성한 후 태그처럼 함수를 호출
- 함수 이름 첫문자는 반드시 대문자

Props: 부모 -> 자식으로 데이터 전달

하위 컴포넌트들에는 실제 값이 없음 -> 최상위 컴포넌트에서 호출할 때 해당값을 넘겨줌

const [ a, setA] = useState(초기값);

주의: 데이터를 배열로 관리할 때는 새로운 배열을 만들어서 넘겨주기

useEffect( callback, [dependency array])
<- 조건을 충족했을 때 callback 수행
: 배열 아예 없으면 랜더링 마다, [] 이면 최초 컴포넌트 마운트 때만 수행

useEffect( func, [count] ) -> count 가 변경될 때마다 func 수행

-> cleanip 함수를 사용해 useEffect를 언마운트 하여 메모리 누수를 방지해야 함

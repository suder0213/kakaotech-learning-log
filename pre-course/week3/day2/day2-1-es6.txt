값의 변경 유무를 파악해 var을 최대한 지양하고 let과 const를 사용하는 것이 바람직함

var는 함수 레벨 스코프
let과 const는 블록 레벨 스코프를 지원하므로 혼란을 야기할 가능성이 적음

화살표 함수
(a, b) => a + b; 처럼 함수를 생략해 작성
const x = (x, y) => x + y ;

구조 분해 할당
const {name, age } = person; 처럼 객체의 프로퍼티 값으 변수에 할당 ( 모든 프로퍼티 할당할 필요 X )

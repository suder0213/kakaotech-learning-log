Early Return - if문 중첩으로 로직을 복잡하게 만드는 대신 실패 조건을 먼져 쳐내고 핵심 로직에만 집중할 수 있도록 하는 패턴

객채지향설계는 상태(필드)와 책임(메소드)를 분리하여 설계한다
- 고치기 쉬움
- 재사용성이 좋음
- 확장성이 좋음

매직 메서드: 특정 상황에서 자동으로 호출되는 메서드
init, repr, eq, str 등

캡슐화: 데이터와 기능을 하나로 묶고, 외부에서 내부의 데이터를 함부로 보거나 수정하지 못하게 막는것
- 필드앞에 _를 붙여 직접 접근 금지 약속
- @property

상속
- 상위 클래스의 속성과 메서드를 사용할 수 있음
- 부모의 기능은 그대로 두고 새로운 기능을 추가할 수 있음
- 오버라이딩: 부모의 기능을 덮어쓰기
- super() -> 부모의 기능 사용

- 다형성: 같은 메서드가 다른 클래스에서는 다르게 작동
- 추상화: 불필요한 세부 사항을 감추고, 설계도 역할을 할 수 있도록 하는 개념

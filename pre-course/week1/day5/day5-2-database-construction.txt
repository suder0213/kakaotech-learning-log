# 1 제약 조건

제약 조건: 데이블에 잘못된 데이터가 입력되는 것을 방지하기 위한 규칙

NOT NULL: 널 값 비허용
UNIQUE: 중복되는 값 비허용
DEFAULT: 아무값을 지정하지 않았을 때 기본값 입력
CHECK: 값의 범위를 제한하여 특정 값만 허용

제약 조건 정의 (CINSTRAINT)
제약 조건 이름을 재정의할 수 있음

제약 조건 추가
ALTER TABLE 테이블명 ADD CONSTRAINT 제약조건이름 제약조건(속성);
ALTER TABLE 테이블명 ALTER 속성명 SET DEFAULT 기본값;

제약 조건 삭제
ALTER TABLE 테이블명 DROP CONSTRAINT 제약조건이름;

# 2 키

조건에 만족하는 튜플을 찾거나 정렬할 떄 기준이 되는 속성

기본키: 서로 다른 튜플을 유일하게 식별할 수 있는 기준이 되는 속성
- 중복 값 x, 널 값 X, 테이블 당 1개
PRIMARY KEY

외래키: 다른 테이블의 기본키를 참조하는 속성으로 테이블의 관계를 정의
FOREIGN KEY 참조할 속성 REFERENCES ㅊ마조되는 테이블(참조되는 속성)

그 외: 후보키, 대체키, 슈퍼키

무결성 제약 조건
- 개체 무결성: 기본키는 널과 중복될 수 없음
- 참조 무결성: 외래키는 널이거나 참조되는 릴레이션의 기본키 값과 동일해야함
- 그외 : 도메인 무결성, NULL 무결성, 고유 무결성, 키 무결성



# 3 데이터 모델링

정의: 현실 세계에 존재하는 데이터를 데이터베이스화하는 과정

데이터 모델: 현실 세계의 데이터를 단순화, 추상화
개체: 데이터로 표현하고자 하는 개념이나 정보(명사)
속성: 개체에 대한 정보
관계: 개체 간의 연관성(동사)

개념적 설계: 현실 세계를 추상적 개념으로 표현
논리적 설계: DBMS가 처리할 수 있는 스키마 설계
물리적 설계: DBMS에 테이블을 저장할 구조 설계

4 ER 다이어그램(Peter Chen)

ERD: 현실 세계의 데이터를 개체와 관계 형태의 다이어그램으로 나타내는 것

개체, 속성, 관계, 개체와 속성의 연결, 기본키 등을 각각의 기호 (네모, 원, 세모, 선, 선이 그어진 원) 으로 표현

5 ER 다이어그램(IE)

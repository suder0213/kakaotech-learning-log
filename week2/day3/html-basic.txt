HTML: 웹 페이지의 구조와 내용
CSS: 웹 페이지의 모양
JS: 웹 페이지의 동적 변경

브라우저: 위 3개의 코드를 그려주는 소프트웨어

마크업 언어: 내그를 사용해 텍스트, 이미지 등을 표현

HTML은 문서작업을 위한 언어 (엄밀히 말하면 프로그램 언어는 아님)

태그: 요소의 시작과 끝을 표기하는 마크업 기호
<태그이름 속성="속성값">콘텐츠</태그이름>

self-closing tag
<br />, <img /> <input />같이 컨텐츠가 필요없는 태그

<html></html> 문서의 처음과 끝

<head> 메타데이터

<body> 웹 페이지의 실제 내용

---------------------------------------
컨테이너
- 요소들을 묶어서 구조화 하거나 스타일링을 적용

<div> block 수준의 컨테이너 ( 한 줄 모두 차지 )
<span> inline 수준의 컨테이너 ( 한 줄에 여러개 할당 )

<중요, class와 id>
class: 페이지 내 동일 스타일 부여
- 같은 스타일을 넣고 싶은 요소에 같은 클래스 부여

id: 요소에 고유한 식별자 부여
- html 문서 안에서 유일해야함

<img src="이미지_파일_경로" alt="대체_텍스트" />

하이퍼 링크 태그는 왜 a지??

<table>: 표를 만들 수 있음
<tr> <th> <td>

<form> 사용자로부터 입력을 받을 수 있는 양식
-method(GET POST 등)
-name 폼의 이름
-action 데이터를 전송할 url 등
<label>: 다른 입력 요소와 연결된 라벨 요소
-for: 입력할 id와 연결
<input> 가장 기본적인 입력 요소
-type: 유형 결정
-placeholder: 입력 힌트
-name: 입력 값의 이름

<textarea>: 여러 줄의 텍스트를 입력
-cols, rows

semantic tag: 사실 모든 시맨티 태그는 div랑 같은 역할을 함 -> 다만 구조적으로 보기 좋음
<header><nav><main><article><aside><footer>

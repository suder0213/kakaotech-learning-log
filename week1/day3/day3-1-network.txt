
# 1 네트워크
전 세계 수 많은 네트워크를 연결한 것 -> 인터넷
인터넷의 본질은 네트워크!
네트워크란: 두 대 이상의 연결하여 데이터를 공유할 수 있게 한 공유 시스템

1. 클라이언트: 서비스를 요청하는 사용자
2. 서버: 클라이언트의 요청에 응답하여 서비스를 제공하는 컴퓨터
3. 통신 프로토콜: 네트워크 상에서 데이터를 교환하기 위한 규칙과 절차


# 2 IP주소
데이터 패킷의 출발지와 목적지를 명시하는 주소
4개의 옥텟(8비트) 로 구성
네트워크 ID와 호스트 ID로 나뉨

43억개의 주소 -> 주소 부족의 한계 발생
-> IPv6 사용
여전히 IPv4를 주로 사용하지만 IPv6 사용도 점점 증가하는 추세

# 3 DNS
아이피 주소는 길고 복잡하고 어려움
IP 주소는 변동될 수 있음
-> 기억하기 쉬운 도메인 이름을 사용

DNS: 도메인 이름과 IP 주소 간 변환을 처리하는 시스템

# 4 Port 번호
많은 기기에 둘 이상 기기가 연결된다면?
-> 포트 번호 사용: 컴퓨터나 기기의 특정 어플리케이션이나 서비스에 연결, 같은 IP를 사용하는 여러 서비스 간 데이터 전송을 구분

사용 중인 포트는 중복해서 사용할 수 없음

지정 포트 번호가 존재함 0 ~ 1023

# 5 네트워크의 종류

WAN, MAN, LAN, PAN

PAN: 개인 장치들 간 연결 스마트폰 무선 이어폰 등
LAN: 제한된 지역 내 컴퓨터 장치 연결, 사무실/학교 컴퓨터
MAN: 도시나 대도시 지역 커버 (공공 와이파이 등)
WAN: 넓은 지리적 범위, 인터넷, 글로벌 기업 네트워크

# 6  네트워크 토폴로지와 통신 방식

네트워크 토폴로지: 컴퓨터 네트워크의 요소를 물리적을로 연결한 구조 및 연결 방식
-> 버스, 스타 토폴로지, 링 토폴로지, 메시 토폴로지 등

통신 방식: 유니캐스트, 멀티캐스트, 브로드 캐스트
유니캐스트: 1:1 통신 방식, 신뢰성 높음
멀티캐스트: 1:N 라이브 스트리밍, 온라인 강의 등
브로드캐스트: 한 송신자가 네트워크 내 모든 대상과 통신, ARP 요청 등

# 7 TCP - IP 프로토콜
IP 프로토콜: 데이터를 목적지까지 전달하는데 사용하는 핵심 프로토콜, 송수신자를 식별하여 패킷단위로 전송
-> 한계: 신뢰성의 문제(전달 과정에서 손실이나 순서에 대한 책임을 지지 않음)

TCP/IP 프로토콜: 데이터가 정확한 목적지에 도달할 수 있도록 하는 통신 규약

응용계층, 전송 계층, 인터넷 계층, 네트워크 액세스 계층으로 나눠짐
-> 캡슐화, 역캡슐화 수행

# 8 TCP와 UDP

TCP: 연결 지향, 3, 4 웨이 핸드셰이크
흐름 및 혼잡 제어 순서 보장
높은 신뢰성, 느린 속도

3 WAY HANDSHAKE: TCP 연결 성립을 위해 3개의 TCP 패킷을 교환하는 통신 방식

4 WAY HANDSHAKE: TCP 연결 종료를 위해 4개의 TCP 패킷을 교환

UDP: 비연결형 지향, 낮은 신뢰성, 순서 보장 X, 빠른 속도, 정보 신호 절차 X

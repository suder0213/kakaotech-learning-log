# 1 데이터베이스 소개

데이터 : 현실 세계에서 수집된 단수한 사실과 값
정보: 데이터를 특정 목적에 의해 해석하거나 가공한 형태

데이터베이스: 데이터들의 집합
공동, 통합, 저장, 운영

무결성: 데이터가 정확하고 일관된 형태로 유지되는 것

데이터베이스의 특징
1. 실시간 접근성
2. 지속적인 변화
3. 동시 공유
4. 내용에 대한 참조(물리적 위치가 아닌 값으로 검색 가능)


# 2 데이터베이스의 종류
RDB, NoSQL

관계형 데이터베이스
- 데이터를 행과 열을 가지는 테이블로 표현
- 테이블 간 관계를 통해 데이터를 효과적으로 관리, 무결성 보장
- 정의된 스키마에 맞게 데이터를 삽입, 안정성 보장
- 데이터의 구조가 일관적인 경우에 사용

RDBMS: 데이터베이스 관리를 위한 시스템
-MYSQL, POSTGRESQL, MARIADB 등

NoSQL
- 유형 제한 없음
- 데이터 구조가 일관적이지 않음
- 대용량 데이터를 더 빠르게 처리할 수 있음

:몽고디비, 레디스, 카산드라 등

# 3 관계형 데이터베이스 만들기

구성요소: 테이블/행/열, 속성, 튜플, 도메인

관계란: 두 테이블을 연결하는 것
- 관계가 없다면 데이터를 중복해서 저장해야하는 경우가 늘어남
- 관계는 보통 ID로 연결

테이블 정의하기: CREATE TABLE 테이블명(속성1 데이터타입1, 속성2, 데이터타입2...)

SHOW TABLES;

DESC 테이블명;

SQL 작성 규칙
- SQL 문법은 대문자로 작성 권장
- 테이블명, 속성은 소문자
- 이름은 의미가 잘 드러나게
- 이름에 여러 단어를 쓰면 _를 사용
- --를 사용해 주석
- 명령어 끝에는 ; 사용

데이터 삽입; INSERT INTO 테이블명(속성1, 속성2, ...) VALUES(속성값1, 속성값2, ...);
: 속성을 순서대로 읩력하는 경우에는 속성 목록 생략가능

데이터출력하기 SELECT 속성1, 속성2, ... FROM 테이블명;

# 4 데이터베이스 정의어

SQL: 관계형 데이터베이스를 활용하기 위해 사용하는 표준언어
1. DDL
2. DML
3. DCL

데이터타입
-VARCHAR(n) 가변 문자열 데이터
-IN: 정수형 (4 바이트)
- FLOAT: (4 바이트 부동 소수점
- DATETIME (YYYY-MM-DD HH:MM:SS 형태의 날짜 및 시간 데이터)

테이블 수정
ALTER TABLE tablename ADD COLUMN
ALTER TABLE tablename MODIFY COLUMN
ALTER TABLE tablename CHANGE COLUMN
ALTER TABLE tablename DROP COLUMN
ALTER TABLE tablename RENAME

테이블 삭제
DROP TABLE

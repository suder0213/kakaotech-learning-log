DOM: 문서 객체 모델
- 구조화된 문서를 객체 형태로 표현하는 방식
- 자바스크립트 엔진이 HTML을 해석한 결과물

document.getElementById()
document.querySelector() 등으로 HTML 요소 선택 가능

createElement로 생성된 노드는 appendChild 등을 통해 DOM에 추가되어야 화면에 보여짐


var myUl = document.querySelector("ul");

//1. for loop을 사용해서 index.html의 <ul></ul> 내에 li 태그 문장 21개를 createTextNode()와 appendChild()를 사용해서 추가합니다.

for (var i = 0 ; i <= 21 ; i ++)
{
    const newText = document.createTextNode("<li>"+ i + "번째 문장</li>");

    // 3. 부모 요소의 마지막 자식으로 추가
    myUl.appendChild(newText);
    
}
위에게 안되는 이유: createTextNode는 순수 텍스트만 전달함. createElement를 사용해서 만들어줘야함

var myUl = document.querySelector("ul");

//1. for loop을 사용해서 index.html의 <ul></ul> 내에 li 태그 문장 21개를 createTextNode()와 appendChild()를 사용해서 추가합니다.

for (var i = 0 ; i < 21 ; i ++)
{
    const newElement = document.createElement("li");
    const newText = document.createTextNode(i + "번째 문장");

    newElement.appendChild(newText);

    // 3. 부모 요소의 마지막 자식으로 추가
    myUl.appendChild(newElement);
    
}

1. html 요소에 on이벤트명으로 추가 (비권장)
2. node 객체에 .on이벤트명
3. addEventListener를 사용하여 리스너 등록

어떤 Element 안에서 getElement를 수행하면 그 Element의 자식 중에서만 찾음

이벤트 발생 시 event 객체에 각 이벤트 발생에 관한 정보를 얻을 수 있음

removeEventListener로 이벤트 리스너 제거도 가능

자식 노드에서 이벤트가 발생하면 DOM 트리를 따라서 상위 요소로 전파됨 - 이벤트 전파
: 부모 요소에서 원하지 않는 핸들러까지 실행될 수도 있음
- event.stopPropagation()을 사용하면 부모로의 전파는 중단됨

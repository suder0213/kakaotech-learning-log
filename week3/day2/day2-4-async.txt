setTimeout: 정해진 시간 후 함수 실행
setInterval: 정해진 시간 마다 함수 반복 실행

실행 컨텍스트
- 자바 스크립트 엔진은 코드 실행 전 실행 컨텍스ㅡㅌ라는 것을 생성함
1. 생성 단계: 변수 선언문 먼저 저장
2. 실행 단계: 나머지 코드 실행, 변수 값 할당
- 각 함수는 각각의 실행 컨텍스트를 가짐 ( 콜스택으로 관리 )

자바 스크립트는 싱글 스레드 기반 언어임. ( 동시에 두가지 작업 불가 )
-> 비동기 처리가 중요함

- 타이머 함수 (시간)
- Ajax (HTTP)
- 이벤트 핸들러 (이벤트 감지)
-> 언제 완료될 지 알 수 없는 작업들

자바스크립트의 비동기 동작 원리
- 이벤트 루프와 태스크 큐를 사용하여 구현
- 태스크 큐: 이벤트 핸들러, 비동기 함수 콜백 함수가 잠시 저장되는 큐
- 이벤트 루프: 콜 스택이 비어있고, 큐가 비어있지 않다면 이를 콜 스택으로 이동시킴

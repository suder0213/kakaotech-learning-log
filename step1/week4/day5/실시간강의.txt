RAG
- 이미지, 텍스트, 오디오 모두 벡터화 하여 데이터 유사도를 평가 가능

RAG는 초창기 방법 -> 개선하여 새로운 RAG, 여러가지 방법론 출현

RAG 구현체
1. keyword search: search + retrieve(hybrid search)
- ex) 휴가 규정이 어떻게 되나?
    -> 휴가 / 휴가 규정 등 키워드를 뽑아 직접 검색
    -> embedding 기반 거리 검색
    -> 두 결과를 prompt에 합쳐서 사용
2. 검색 -> 정제
    - 끊기거나 불완전한 정보를 원상 복귀
3. 질문을 정제
    - 대화를 할 때 묻는 정보들을 정제 (어떤 것에 대한 질문인가? 의도가 무엇인가?)
    - ex) 제주도 여행 계획 짜줘
        - 여행지? 일정? 가격? <- 이런 것들을 미리 어떻게 해라 그런 것들 설계
    - ex) 내일 일정 찾아줘
        - 내일이 언제? <- system: 내일 날짜를 반환

re-reanking: 검색 결과의 중요도를 모델이 다시 정리

Agent: 질문을 어떻게 하면 LLM을 더 잘 쓸 수 있을까?
    Context를 어떻게 구성해야 모델이 더 잘 이해할 수 있을까?

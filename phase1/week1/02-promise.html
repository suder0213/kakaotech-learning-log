Promise 흐름 실습

Promise란?

Promise는 "지금 당장 값이 없지만, 나중에 성공하거나 실패할 작업"을 표현하는 객체예요.
서버에서 데이터를 가져오는 것처럼, 얼마나 걸릴지 모르는 비동기 작업을 다룰 때 사용해요.

왜 필요한가?

JavaScript는 싱글 스레드라 한 번에 하나의 작업만 처리해요.
서버 응답을 기다리는 동안 브라우저가 멈추면 안 되니까, JS는 기다리는 대신 "나중에 결과 오면 이걸 실행해" 라고 등록만 하고 다른 일을 먼저 처리해요.
이 "나중에 할 일을 등록하는 방식"이 비동기 처리이고, Promise는 그걸 깔끔하게 표현하는 도구예요.

Promise의 3가지 상태

상태 의미 전환 가능
pending 아직 결과를 모름 (대기 중) fulfilled 또는 rejected로 전환
fulfilled 성공적으로 완료됨 더 이상 변하지 않음 (불변)
rejected 실패 (에러 발생) 더 이상 변하지 않음 (불변)

※ 한번 fulfilled/rejected가 되면 상태가 절대 바뀌지 않아요.

기본 문법

const p = new Promise((resolve, reject) => {
  // 비동기 작업 수행
  if (성공) resolve(결과값);   // → fulfilled
  else     reject(new Error()); // → rejected
});

p.then(result => { /* 성공 시 실행 */ })
 .catch(err    => { /* 실패 시 실행 */ })
 .finally(()  => { /* 성공/실패 상관없이 항상 실행 */ });

흐름 요약

  new Promise(...)
        │
        ▼
    [pending]  ← 지금 이 상태
     /      \
resolve()  reject()
   /            \
[fulfilled]  [rejected]
    │               │
  .then()        .catch()

async / await 와의 관계

async/await는 Promise를 더 읽기 쉽게 쓰는 문법적 편의 기능(syntactic sugar)이에요.
내부 동작은 완전히 동일하고, await는 Promise가 fulfilled/rejected 될 때까지 그 함수 안에서만 기다려요.
브라우저 전체를 멈추는 게 아님에 주의하세요.

.then / .catch 인자에는 뭐가 들어오나?

.then(result => ...)의 result에는 resolve(값)에 넘긴 값이 자동으로 전달돼요.
.catch(err => ...)의 err에는 reject(값)에 넘긴 값이 자동으로 전달돼요.
체이닝일 때는 이전 .then 안에서 return한 값이 다음 .then의 인자가 돼요. (return 생략 시 undefined) 

Promise.resolve(10)
  .then(n => n * 2)       // return 20
  .then(n => n + 5)       // n = 20,  return 25
  .then(n => console.log(n)); // 25

fetch는 왜 바로 .then을 붙일 수 있나?

fetch()는 브라우저에 내장된 함수인데, 호출하면 Promise를 반환하도록 만들어져 있어요.
그래서 반환값이 Promise 객체이고, Promise니까 바로 .then을 붙일 수 있는 거예요. 

// fetch 내부가 대략 이렇게 생겼다고 이해하면 됨
function fetch(url) {
  return new Promise((resolve, reject) => {
    // HTTP 요청 보내고
    // 응답 오면 → resolve(response)
    // 네트워크 오류면 → reject(error)
  });
}

// 그래서 이게 가능한 것
fetch('https://api.example.com/user')  // Promise 반환
  .then(res => res.json())            // .then 가능
  .then(data => console.log(data))
  .catch(err => console.error(err));

※ fetch를 특별한 무언가로 볼 필요 없어요.
이 파일의 fakeApi()와 구조가 완전히 동일한, "Promise를 반환하는 함수"일 뿐이에요.

버튼을 눌러 실행하세요...

1. Promise 기본 (상태: pending → fulfilled / rejected)

Promise는 pending → fulfilled(성공) 또는 rejected(실패) 세 가지 상태만 존재.

2. .then / .catch 체이닝

성공은 .then, 실패는 .catch. 체인 중 어디서든 throw 하면 .catch로 점프.

3. async / await (Promise의 문법 설탕)

await는 Promise가 끝날 때까지 기다림. 내부 동작은 .then/.catch와 동일.

4. Promise.all — 여러 개를 동시에

모두 성공하면 결과 배열 반환. 하나라도 실패하면 즉시 reject.

5. Promise.allSettled — 실패해도 3개 다 출력

실패한 게 있어도 전부 끝날 때까지 기다리고 3개 모두 결과를 줌.
각 결과는 성공이면 { status: 'fulfilled', value }, 실패면 { status: 'rejected', reason }.

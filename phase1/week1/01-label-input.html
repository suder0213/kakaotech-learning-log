❌ label 없이 그냥 input

→ 클릭 가능 영역이 input 박스뿐.
→ 스크린리더가 "이 입력칸이 무엇인지" 모름 (접근성 없음).
→ 자동완성도 힌트 부족.

이름:

✅ label로 제대로 연결한 경우

→ "이름" 텍스트를 클릭해도 input이 포커스됨 (클릭 영역 확장).
→ 스크린리더가 "이름 입력칸"이라고 읽어줌 (접근성 OK).
→ for="xxx" 와 id="xxx" 가 일치해야 연결됨.

⚠️ for/id가 불일치하는 경우

→ label의 for="wrong-id" 인데 input의 id="email" → 연결 안 됨.
→ "이메일" 텍스트를 클릭해도 input이 포커스되지 않음.
→ 시각적으로는 옆에 있어도 의미상 연결이 끊어짐.

🔀 for/id가 엇갈린 두 쌍

→ "이름" 클릭 시 → 이메일 input이 포커스됨 (엉뚱한 칸으로 연결).
→ "이메일" 클릭 시 → 이름 input이 포커스됨.
→ 스크린리더도 "이름 편집 필드"라고 읽는데 실제로는 이메일 칸 → 혼란.
→ 시각적 순서와 논리적 연결이 달라서 UX/접근성 모두 망가짐.
